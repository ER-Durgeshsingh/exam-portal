# Online Exam Portal (React + Node + MySQL)

## Setup
1. MySQL mein `server/schema.sql` run karo (sample exam bhi add ho jayega).
2. `cd server && cp .env.example .env` -> DB password daalo. Phir `npm install && npm start`
3. `cd client && npm install && npm run dev` -> http://localhost:5173
4. Register karo (Admin ya Student) aur login karo.

## Features
- JWT login, student/admin roles
- Admin: exam + MCQ create karna, sabhi results dekhna
- Server-side timer + auto-submit, auto-evaluation (correct answers client ko nahi jaate)
- Anti-cheat: tab switch, fullscreen exit detect; copy/paste/right-click block; 3 violations par auto-submit
